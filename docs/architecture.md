# 架构与接口

## FPGA实时层

摄像头DVP字节由`DVP_Capture`组合为RGB565像素，经过水平滤波写入DDR3，再由显示域按HDMI时序读出。`rgb_neutral_trim`将读出RGB565映射为补偿后的RGB888；IMU文本叠加和OSD模式选择在显示端完成。

IMU接收器解析带校验的姿态帧，坐标转换后同时用于OSD与运动/导航。编码器提供速度/里程反馈，PID调节电机输出。任务三和任务四通过仲裁接管运动命令，安全门优先处理急停和失效状态。

主要时钟域为摄像头PCLK、控制PLL 50MHz、显示75MHz及DDR PHY相关时钟。OSD模式采用req/ack邮箱跨域；发布方在收到应答前保持数据稳定，接收方在帧边界改变显示模式。

## RK3588智能层

FPGA HDMI输出接RK3588 HDMI-IN。检测器通过V4L2持有采集缓冲，RKNN上下文常驻执行推理，输出检测框和红色区域统计。目标关联层维护指定物体身份，策略层将目标/距离转为运动请求，最终门控统一限速和停车。

任务六同时利用左右半幅红色统计，降低大红色书包掩盖小红瓶时的方位干扰。颜色线索用于引导，类别和目标身份用于确认；两者的作用不能互相替代。

## 连接

| 连接 | 用途 |
|---|---|
| OV5640 → FPGA DVP | 图像采集 |
| IMU → FPGA UART | 姿态输入 |
| 编码器/超声波 → FPGA | 运动反馈、距离 |
| FPGA HDMI → RK3588 HDMI-IN | AI视觉输入 |
| RK3588 UART → FPGA | 模式、视觉及运动请求 |
| FPGA CH340 USB → RK3588 | 状态遥测 |
| PC ↔ RK3588网络 | 网页、SSH与文件传输 |

引脚的权威配置是[FPGA约束](../fpga/src/ov5640_ddr3_hdmi.cst)。设备串口号由实际系统枚举确定；网页默认命令口`/dev/ttyS0`、遥测口`/dev/ttyUSB0`，支持环境变量覆盖。
